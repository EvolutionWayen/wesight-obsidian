# WeSight for Obsidian 1.3.0

发布日期：2026-10-14。

新增当前知识库的 GitHub 团队协作、手动提交与提交说明生成，完善飞书连接器与授权续期，并提供插件内近期版本更新说明。

## GitHub 团队协作

- 头像菜单显示当前仓库、分支、同步状态及待拉取和待推送数量，提供立即拉取、推送提交、仓库同步设置和同步记录。未登录 WeSight 也可从本地头像打开同步菜单。
- 有文件修改时显示「提交并推送」，先选择文件、填写提交说明，再提交、拉取团队更新并推送。未选择的文件和其他工具暂存的内容保持原样。
- 提交窗口自动根据所选文件的真实差异生成本机摘要，可重新总结、手动编辑，或点击「AI 总结」使用当前默认 Agent 和模型生成说明。AI 仅分析所选文件的有限差异，生成期间的手动编辑会保留，关闭窗口会取消生成。
- 新增「设置 → WeSight → 仓库同步」，分别配置定时拉取、启动时拉取、自动推送和停止编辑后的自动提交。自动化默认关闭，保存后仅作用于此设备的当前知识库。
- 自动提交遵循 `.gitignore` 和自定义排除路径，默认排除聊天记录与环境文件，始终排除当前 Obsidian 配置目录。较大仓库内的子知识库只自动提交自身目录中的修改。
- 拉取可合并独立的团队修改；本地未提交修改、合并冲突、分支或远程变更时暂停相关操作并提示处理。网络或推送失败时保留本地提交，同步不会强制推送、自动 stash 或 reset。
- 新增立即拉取、推送提交、检查远程更新及打开同步设置的命令，可绑定快捷键。配置与最近 30 条记录按知识库路径保存在本机 WeSight 目录。

## 飞书连接器与使用体验

- 通用设置新增飞书连接器卡片，可连接、重新检测、查看账户与授权状态，以及主动断开连接。
- 飞书 access token 需要刷新且 refresh token 仍有效时，复用 CLI 自动续期，减少重复扫码。插件启动后及每 6 小时对已有授权尝试后台续期，失效或撤销的授权仍需重新连接。
- 首次安装自动打开 WeSight 侧栏；已有设置的用户升级后保持原来的工作布局。
- 头像菜单与通用设置新增「版本更新说明」，离线可查看 1.3.0、1.2.2、1.2.1、1.2.0、1.1.0 和 1.0.0 的更新内容。

## 升级与验证

- 最低支持桌面版 Obsidian 1.11.4。手动更新使用本 Release 的 `main.js`、`manifest.json`、`styles.css`，更新后关闭再开启 WeSight 或重启 Obsidian。
- Git 协作需要本机安装 Git、当前分支设置远程跟踪分支，并具有相应仓库权限。每台协作设备分别开启自动化。
- `npm run check` 通过：545 项测试通过，1 项可选测试跳过；lint 无错误，类型检查、生产构建与发布资源校验通过。Git 测试使用两个本地协作仓库，覆盖拉取、推送、自动提交、冲突与文件保留、提交范围、说明生成和窗口交互。
- 已在真实 Obsidian 知识库验证头像菜单、手动提交窗口、本机差异摘要及插件重载；文章内容的最终提交由用户确认。
- AI 总结使用当前模型配置及其额度；本次通过模拟运行时验证请求范围、只读运行和取消行为，实际模型输出随所选服务变化。
